## Explicação do sistema

O projeto foi desenvolvido para registrar solicitações técnicas internas de uma empresa.

O sistema permite cadastrar solicitações contendo:

- nome do funcionário
- departamento
- descrição do problema

As informações são armazenadas no banco de dados MySQL e compartilhadas em rede local utilizando IPv4.
